# 📄 GenAI PDF Chatbot using LangChain & Groq

An AI-powered PDF chatbot that allows users to upload PDF documents and interact with them using natural language. The application uses Retrieval-Augmented Generation (RAG) to extract information from uploaded PDFs and generate intelligent responses.

🚀 **Live Demo:**  
https://genai-pdf-chatbot-tyrjexwa76zdfzqsy7x5jj.streamlit.app/

---

## 📌 Project Overview

GenAI PDF Chatbot is a Generative AI application built using **LangChain, Groq LLM, FAISS Vector Database, and Streamlit**.

Users can upload any PDF document, ask questions, and receive context-aware answers generated from the document content.

The project demonstrates practical implementation of **RAG (Retrieval-Augmented Generation)** architecture commonly used in modern AI applications. :contentReference[oaicite:0]{index=0}

---

## ✨ Features

✅ Upload PDF documents  
✅ Extract text from PDFs  
✅ Automatic text chunking  
✅ Generate embeddings for document search  
✅ Store embeddings using FAISS Vector Database  
✅ Ask questions in natural language  
✅ AI-powered answers using Groq LLM  
✅ Fast and interactive Streamlit interface  
✅ Deployed on Streamlit Cloud

---

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Frontend:** Streamlit
- **LLM Framework:** LangChain
- **Large Language Model:** Groq LLM
- **Vector Database:** FAISS
- **Embeddings:** HuggingFace Embeddings
- **PDF Processing:** PyPDF
- **Deployment:** Streamlit Cloud
